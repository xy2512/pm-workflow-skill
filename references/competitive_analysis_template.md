## 竞品分析输出要求

1. 至少分析 **2 个直接竞品** + **1 个间接竞品/替代方案**
2. 不仅要列功能，更要分析**用户选择/离开的深层原因**
3. 基于分析结论，明确 **1-2 个差异化切入点**（必须可量化或可感知）
4. 将竞品分析结果纳入 PRD 第四章「市场定位与竞品摘要」

## 数据来源建议

| 来源 | 获取方式 | 可得信息 |
|---|---|---|
| 产品官网/应用商店 | 直接访问 | 功能介绍、定价、用户评分 |
| 用户评论分析 | App Store/应用市场/社区 | 真实用户反馈、痛点、好评点 |
| 第三方数据平台 | SimilarWeb/七麦/QuestMobile | 流量、用户量、增长趋势 |
| 社交媒体/社群 | 微博/知乎/V2EX/小红书 | 用户讨论、吐槽、需求 |
| 投资数据库 | IT桔子/36kr/Crunchbase | 融资情况、团队背景 |
